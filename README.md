# ❤️ Parashikimi i Sëmundjes së Zemrës

Klasifikim i sëmundjes së zemrës me Logistic Regression mbi dataset-in UCI Heart Disease (303 pacientë, 13 feature klinike): pastrim, heqje outliers (3σ), StandardScaler — 84.21% saktësi në test set. Demo-ja ndërvepruese llogarit rrezikun nga 13 parametrat klinikë.

## 🚀 Si ta hapësh

Hap `index.html` — tab-i **Live Demo** ekzekutohet direkt në browser, ndërsa tab-i **Kodi Burim** tregon kodin e plotë (demo + origjinali i paprekur).
